# Licensing

Which version of cigo is under which license, in one table. The
[LICENSE](LICENSE) file is the text that governs the current code; this page
records the history and says where to ask for anything else.

| Versions | License | Notes |
|---|---|---|
| Every release through v1.18.0, and every commit up to the one tagged `apache-2.0-last` | Apache-2.0 | Copies taken in this range stay under Apache-2.0. The last release in it is v1.18.0 (2026-11-10). |
| From the licensing commit on, including every release made after it | FSL-1.1-ALv2 | Each version converts to Apache-2.0 on the second anniversary of the date it is made available. |
| Documentation, all versions | CC-BY-4.0 | [REUSE.toml](REUSE.toml) maps every path. |

## The Apache-2.0 period

cigo was published under Apache-2.0 and every release up to v1.18.0 was made under it. The commit before the licensing change is marked by the tag
`apache-2.0-last`. That grant is permanent for any copy taken in that period.
On 2026-11-11 GitHub recorded no forks of the repository.

## Terms the license does not give

Jay Taylor holds the copyright and can license the code on other terms. To ask,
open an issue on [this repository](https://github.com/otmof-ops/cig-orchestrator/issues)
saying what you want to do. Security problems go through the private reporting
described in [SECURITY.md](SECURITY.md), not an issue.

The names are covered separately by [TRADEMARKS.md](TRADEMARKS.md).
Dependencies keep their own licenses.
